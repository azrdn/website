![pnpm >= 11](https://img.shields.io/badge/pnpm-%3E%3D11-blue) 

My hybrid SSR/SSG site

Requirements:
- Node.js
- PNPM
- PostgreSQL Database

### develop
- fill and rename .env.example file to .env
- run `pnpm dev`
- go wild

### deploy
- same first step as development
- run `pnpm build`
- results in `dist` directory
- and then you deploy
